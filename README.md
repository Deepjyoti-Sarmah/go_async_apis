# Go Async API 

This repository demonstrates how to build asynchronous APIs in Go using channels and goroutines. It provides a basic framework for handling asynchronous tasks, such as processing data in the background or interacting with external services.

## Features

*   Asynchronous task processing using goroutines and channels.
*   Example API endpoint for submitting asynchronous tasks.
*   Simple task management and status tracking.
*   Demonstrates error handling in asynchronous operations.

## Getting Started

### Prerequisites

*   Go 1.20 or higher

### Installation

1.  Clone the repository:

    ```bash
    git clone https://github.com/Deepjyoti-Sarmah/go_async_apis.git
    ```

2.  Navigate to the project directory:

    ```bash
    cd go_async_apis
    ```

3.  Build the application:

    ```bash
    go build -o async_api .
    ```
